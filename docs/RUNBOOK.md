# Эксплуатация сайта «Центр Квелити»

## Первый запуск (любой сервер с Docker, провайдер не важен)
(Сначала прочитайте раздел «Админ-панель (Directus)» ниже: на шаге 4 нужны два домена.)
1. Создайте сервер (Ubuntu LTS), отключите вход по паролю, оставьте SSH-ключи, включите firewall: открыты только 22, 80, 443.
2. Установите Docker и `restic`. Склонируйте репозиторий в `/opt/quality`.
3. `cp .env.example .env`, заполните значения (пароли — длинные случайные).
4. Направьте A-записи двух адресов на сервер: `SITE_DOMAIN` (сайт) и `ADMIN_DOMAIN` (админ-панель). Затем `docker compose up -d --build`. HTTPS-сертификат Caddy выпустит сам.
5. Проверка: `curl -I https://ВАШ_ДОМЕН` отдаёт 200.

## Обновление сайта
`git pull && docker compose up -d --build`. Откат: `git checkout <прошлый коммит>` и та же команда.

## Резервные копии
- Политика: 7 ежедневных, 4 недельных, 3 месячных; шифруются restic, хранятся в отдельном S3-бакете.
- Расписание: `infra/backup/crontab.example`.
- Восстановление: `infra/backup/restore.sh имя_базы`.
- Проверка восстановления раз в квартал: `infra/backup/restore-check.sh` (код возврата 0 = успех).
- `RESTIC_PASSWORD` храните также вне сервера: без него копии не открыть.

## Секреты
Только в `.env` на сервере (права 600). В git их нет. При подозрении на утечку — смените пароли и перезапустите.

## Заявки
Публичных форм и приёма заявок на сайте нет. Старый проект с таблицей `leads` (Lovable Cloud/Supabase) сайтом не используется; его нужно закрыть или удалить в его собственной панели управления.

Развёртывание на тестовом сервере через GitHub Actions: [DEPLOY-TEST.md](DEPLOY-TEST.md).

## Админ-панель (Directus)
Панель работает на `ADMIN_DOMAIN` по HTTPS. Саморегистрации нет, публичного доступа к данным нет. Вход возможен только с кодом TOTP.

### Первоначальная настройка (один раз после первого запуска)
Команды выполняются в контейнере CMS; адрес API внутри контейнера — `http://localhost:8055`:
```
docker compose exec -e PUBLIC_URL=http://localhost:8055 cms node scripts/apply-schema.mjs   # коллекции и поля
docker compose exec -e PUBLIC_URL=http://localhost:8055 cms node scripts/apply-access.mjs   # роли, права, обязательный TOTP
docker compose exec -e PUBLIC_URL=http://localhost:8055 cms node scripts/seed.mjs           # услуги и вопросы из seed/data.json
```
Скрипты безопасно запускать повторно. `seed.mjs` при повторном запуске перезаписывает услуги и вопросы значениями из `cms/seed/data.json`, поэтому после начала редактирования в панели его больше не запускают.

### Сотрудники
Администратор и редактор создаются скриптом: он ставит TOTP сразу, и войти без кода из приложения нельзя.
```
docker compose exec -e PUBLIC_URL=http://localhost:8055 cms node scripts/create-user.mjs name@company.ru Администратор
docker compose exec -e PUBLIC_URL=http://localhost:8055 cms node scripts/create-user.mjs name@company.ru Редактор
```
Скрипт печатает временный пароль и секрет TOTP. Секрет вводится в приложение-аутентификатор (Google Authenticator, Яндекс Ключ, Aegis) вручную. Пароль и секрет передавайте разными каналами. После первого входа смените пароль в профиле.
Для самого первого администратора (`ADMIN_EMAIL` из `.env`) выполните ту же команду с его адресом: она задаст ему новый пароль и TOTP.

### Права
- Администратор: всё.
- Редактор: услуги, вопросы, статьи, страницы, данные компании, калькулятор (позиции прайса и правила), файлы. Пользователей, роли, настройки и адреса-перенаправления не видит и не меняет.
- «Читатель сайта»: служебный пользователь с токеном `DIRECTUS_TOKEN`, только чтение. Сайт запрашивает у него только опубликованное.
- Журнал действий (кто и что изменил) ведётся Directus автоматически: раздел «Журнал активности».

### Ограничения бесплатной версии Directus
Права вида «только опубликованные записи» и «только свой профиль» требуют лицензионного ключа Directus, поэтому фильтр по статусу делает сайт, а секрет TOTP записывает скрипт. Если CMS остановится, сайт показывает последнюю загруженную копию (кэш в памяти на время работы процесса). После перезапуска сайта без доступа к CMS страницы услуг не откроются.
